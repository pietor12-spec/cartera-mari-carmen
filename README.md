# Cartera Mari Carmen

Registro personal de movimientos de inversión (compras, ventas, resumen de activos, evolución y comparativa con MSCI ACWI).

- **Abrir la app:** https://pietor12-spec.github.io/cartera-mari-carmen/
- **Instalar:** menú ☰ → «📲 Instalar app» (Android/PC con Chrome o Edge). En iPhone/iPad: Safari → Compartir → «Añadir a pantalla de inicio».
- **Datos:** se guardan en el propio dispositivo (localStorage del navegador) y la app funciona sin conexión. Para pasarlos a otro dispositivo o hacer copia: menú ☰ → «💾 Guardado · importar / exportar».

Publicada con GitHub Pages desde la rama `main`.
